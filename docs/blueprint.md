# **App Name**: Model Toolkit

## Core Features:

- Model Library: Display a curated list of business and productivity models.
- Interactive Model Canvas: Interactive canvas for each model to allow users to add, edit, and delete items.
- Drag & Drop: Enable drag-and-drop functionality for moving items between model blocks.
- Export Options: Provide options to export the model as a PDF or PNG file.
- AI-Powered Insights: Employ an AI tool that analyzes the user's input on the model canvas and offers suggestions for insights and improvements based on best practices.
- Blog Integration: Display blog articles related to business and personal productivity.
- User Feedback: Enable users to submit feedback on the models, ease of use, usefulness, and overall design.

## Style Guidelines:

- Primary color: Indigo (#4B0082), providing a sense of sophistication and intelligence, aligning with the strategic nature of the models.
- Background color: Very light lavender (#F0F0F8), nearly white but with a tint of the primary hue to give a calm, professional backdrop.
- Accent color: Sky blue (#87CEEB), which offers a refreshing contrast to the indigo, for CTAs and interactive elements.
- Headline font: 'Space Grotesk' (sans-serif), suitable for headlines, capturing the app's tech-forward focus; body font: 'Inter' (sans-serif) for readability and a clean aesthetic.
- Use minimalist icons that represent each model's purpose. Icons should use the primary and accent colors.
- Left sidebar for model navigation, central canvas for interactive model building.
- Subtle transitions and animations to guide users through interactions. For instance, a smooth transition when dragging and dropping items on the canvas.
